# Contour — Mexican Pastries Website

A responsive, multi-page static storefront starter for Contour.

## Pages
- `index.html` — Landing page with product highlights, catalogue CTA, About the Team section, values and newsletter UI.
- `about.html` — Company story, values, team and contact CTA.
- `products.html` — Catalogue with category filters, sorting and add-to-bag actions.
- `product.html` — Product detail page, selected with a query string (for example `product.html?id=concha`).
- `terms.html` — Terms of Service starter copy with privacy and food/allergen sections.
- `assets/style.css` — Responsive visual styling.
- `assets/app.js` — Product data, catalogue filters, bag/cart UI, quantity controls and newsletter demo.

## Run locally
Open `index.html` in a browser. No build step or dependencies required. For a more reliable local preview, run a static server such as VS Code Live Server.

## Important before launch
1. Replace `hello@contour.example` with a real company email and add verified company contact/legal details.
2. Confirm product prices, ingredients, allergens, availability, delivery and refund terms. The prices are sample USD prices.
3. Product art is CSS illustration; replace with licensed, authentic product photos when available.
4. Cart and newsletter are front-end demos only. They do not submit orders, send email, or accept payment.
5. Review terms and privacy language with qualified counsel before commercial use.
6. Verify the claim about serving five-star restaurants before publishing if it must be substantiated.
